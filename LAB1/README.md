# Color Converter Var1

Интерфейс программы интуитивно понятен и разделен на три секции, соответствующие цветовым моделям: RGB, CMYK и LAB. Все изменения в приложении синхронизируются в реальном времени.

Вы можете установить нужный цвет тремя различными способами:

1.Интерактивные ползунки: Двигайте слайдеры в любой из секций, чтобы плавно настраивать цветовые компоненты и наблюдать за изменениями.
2.Точный ввод значений: Вводите конкретные числа в поля ввода (SpinBox) справа от ползунков. Значения ограничены допустимыми диапазонами для каждой модели (например, 0-255 для RGB, 0-100 для CMYK).
3.Системная палитра Qt(чтобы наглядно выбрать цвет и посмотреть как они описывается разными системами): Нажмите на квадратный цветовой индикатор в левом верхнем углу. Откроется стандартная расширенная палитра.

Если при изменении ползунков в секции LAB вы зададите цвет, который физически не может существовать в пространстве RGB (то есть расчетные координаты уходят за пределы [0, 255]), программа выполнит безопасное обрезание до ближайших допустимых границ (0 или 255). В этот момент под цветовым квадратом появится текстовое предупреждение красного цвета, сигнализирующее о том, что произошла потеря точности из-за выхода за границы цветового охвата. Аналогично для CMYK.
